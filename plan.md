# Raw Value Preprocessing Plan

## Goal

Keep continuous numerical values in their original units during preprocessing.
Quantile transforms or other scaling should be fitted later inside the model
training workflow.

The preprocessed datasets are named:

- `source`: variables known at conditioning time
- `target`: variables to predict/generate

This applies to source numerical continuous features and target numerical
continuous features. Categorical one-hot features, numerical flag indicators,
bottom/top indicators, missing indicators, and target masks keep their existing
behavior.

## Current Behavior

`preprocess.py` now stores numerical `__value` columns as raw numeric values.

For source numerical features:

- valid numeric values are kept in their original units
- flag and missing values are set to `0.0` in the continuous column
- flag and missing information is still retained in indicator columns
- bottom/top values remain part of the raw continuous data and also get their indicators

For target numerical features:

- valid numeric targets are kept in their original units
- flag and missing targets are set to `0.0`
- `target_mask` is `0` for flag/missing targets, so they do not contribute to loss
- bottom/top values are not masked

## Saved Metadata

Column metadata uses:

```text
raw_value
```

for numerical continuous columns.

Canonical summary files:

- `preprocessed/source_raw_value_summary.csv`
- `preprocessed/target_raw_value_summary.csv`

Their `method` column is now:

```text
raw_value
```

and they store summary statistics for valid raw values:

```text
source_variable,column_name,role,method,n_values,n_unique_values,min_value,max_value,median_value,placeholder_value
```

Canonical array and column metadata files:

- `preprocessed/source_array.npy`
- `preprocessed/source_columns.csv`
- `preprocessed/target_array.npy`
- `preprocessed/target_mask.npy`
- `preprocessed/target_columns.csv`

Quantile lookup CSV files are no longer generated by preprocessing. If stale
lookup files exist in `preprocessed/`, the save step removes them.
